# RLHF 学习课程：从小白到资深对齐专家

> RLHF Course — from Zero to Pro Alignment Expert

一套 **13 阶段 · 35 课** 的 RLHF/对齐学习路线与逐课讲义（纯讲解版，讲授模式，不依赖 GPU 实跑；关键实操课走云端按需）。

- 学习方案：《[RLHF学习方案.md](RLHF学习方案.md)》——路线、原则、阶段拆解、里程碑、论文清单、费用护栏
- 课程讲义：《[RLHF学习课程讲义.md](RLHF学习课程讲义.md)》——每课逐讲（目的 / 历史动机 / 原理 / 代码演示 / 坑 / 验收）

## 课程地图（13 阶段 35 课）

- **阶段0 语言模型与对齐**（课1–2）——LM=概率分布+采样+困惑度；2026 模块化对齐全景
- **阶段1 SFT 深度**（课3–4）——指令数据格式 + LoRA 原理；本机 0.5B 实跑对比
- **阶段2 偏好数据与奖励模型**（课5–6）——偏好协议 + Bradley-Terry + 手搓最小 RM；reward hacking 预警
- **阶段3 经典 RLHF：PPO**（课7–9）——策略梯度 → PPO 数学推导；手写最小 PPO
- **阶段4 现代主力：DPO 家族**（课10–12）——DPO 数学独立推导；KTO/ORPO/SimPO/在线 DPO
- **阶段5 推理强化：GRPO+RLVR**（课13–15）——DAPO 修正 + RLVR 优势计算；AutoDL 实跑 1.5B 数学题
- **阶段6 Agent/工具调用 RL**（课16–17）——工具调用 = 可验证 RLVR 信号（衔接 llm-router-learning）
- **阶段7 评测与 Judge**（课18–20）——RewardBench / MT-Bench / Arena-Hard；LLM-as-judge 偏差
- **阶段8 安全对齐 2026**（课21–23）——越狱 / Constitutional AI / RLAIF / agent 安全
- **阶段9 资深前沿**（课24–26）——推理时对齐（Best-of-N）+ 机械可解释性（SAE）
- **阶段10 毕业设计**（课27–28）——端到端项目（选型→训练→评测→成本→安全）
- **阶段11 生产落地**（课29–32）——OpenRLHF / verl 大规模基础设施；reward 漂移监控
- **阶段12 研究前沿与收官**（课33–35）——可扩展监督、研究设计、综合答辩

> ★ = 关键算法代码演示课；▲ = AutoDL 云端实操课（费用护栏见方案，上限 ¥500）。完整课表见《RLHF学习方案.md》。
